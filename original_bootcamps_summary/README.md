# Original bootcamp project — curated retrospective

This folder is a compact, evidence-oriented summary of the **first RASFF machine-learning project** completed during the bootcamp.

It preserves what the original project actually did and what its stored outputs showed, without rewriting the first project as if it had already used the later audited methodology.

## Read in order

1. `NB1_Cleaning_Hazard_and_EDA.ipynb`
2. `NB2_Features_and_Targets.ipynb`
3. `NB3_Key_Experiments.ipynb`
4. `NB4_Selected_Model_and_App.ipynb`

The selected historical run reported approximately:

- test accuracy: **0.8736**
- macro F1: **0.87**
- serious precision: **0.86**
- serious recall: **0.91**

Those values belong to the original project's own representation and random stratified split. They are **historical evidence, not the evaluation result of the current rebuild**.

## Relationship to the current project

This folder answers:

> What did I build and learn in the first project?

The current [`../RASFF_Rebuild/`](../RASFF_Rebuild/) answers a different question:

> What remains after auditing the problem definition, preprocessing, temporal evaluation, calibration, and app inference path?

Keeping both versions makes the development history explicit instead of silently replacing the original work.
