# 새 RASFF 프로젝트 실행 안내

## 먼저 정한 방향

- Hazard_Type과 simplified_hazard는 필수 변수가 아닙니다. 두 변수 없이 원래 subject와 hazards 등을 활용한 모델을 먼저 만들었습니다.
- 가공 변수는 원본 위해 문자열의 세부정보를 줄이거나 LLM 분류 오류를 추가할 수 있습니다. 반대로 표현을 단순화해 도움이 될 수도 있어, 효과는 같은 조건의 비교로 확인해야 합니다.
- 사용자 선택에 따라 기본 경로에서는 제외하고, 두 변수를 포함한 비교를 선택 실행으로 제공합니다. 기존 값을 읽을 뿐 LLM을 새로 호출하지 않습니다.
- 예측 타깃은 통보에 기록된 serious 여부입니다. 미래 리콜·실제 오염·전체 식품의 안전성을 예측한다는 의미가 아닙니다.

## 실행 순서

1. ZIP 전체를 압축 해제합니다. 노트북과 rasff_core.py, app.py, data 폴더가 같은 상위 폴더에 있어야 합니다.
2. Python 3.12 가상환경을 만들고 터미널에서 `python -m pip install -r requirements.txt`를 실행합니다. 세부 명령은 README.md에 있습니다.
3. VS Code에서 노트북을 열고 설치한 Python 환경을 커널로 선택합니다.
4. 01 → 02 → 03 → 04 순서로 실행합니다. 02의 모델 비교는 컴퓨터에 따라 수분 걸릴 수 있습니다.
5. 터미널에서 `python -m streamlit run app.py`를 실행합니다. 표시된 로컬 주소를 브라우저로 엽니다.

학습된 모델과 이번에 실제 계산한 결과도 포함했습니다. 같은 라이브러리 환경에서는 설치 후 앱을 바로 열 수도 있습니다. 처음부터 과정을 이해하려면 노트북 순서대로 실행하세요.

## 가공 변수 비교를 나중에 해보려면

02편의 `INCLUDE_DERIVED_ABLATION = True`로 바꿉니다. 동일한 C=1 설정의 ablation_raw_lr와 ablation_derived_lr를 비교합니다. 이 결과는 별도 진단이며 이미 선택한 기본 모델을 자동으로 바꾸지 않습니다. 더 좋은 점수를 보고 가공 변수를 실제 채택하기로 결정한다면, 기존 최종 테스트를 재사용해 튜닝하지 말고 새 평가 계획을 세워야 합니다.

`INCLUDE_LATE_DIAGNOSTIC`는 classification의 영향만 별도로 확인하는 설정입니다. 이 변수가 예측 시점에 사용 가능했는지는 검증되지 않았으며 기본 앱 모델에는 들어가지 않습니다.

## 대시보드에서 할 수 있는 일

- 연도와 날짜 범위, 품목, 유형, 원산지, 통보 국가, 통보 유형, 위험 판단으로 기록을 필터링합니다.
- 제목과 원래 위해 텍스트를 검색하고, 월별·항목별 건수와 원자료를 확인합니다.
- 필터링한 CSV를 다운로드합니다.
- 저장된 모델에 필요한 입력을 넣어 serious 기록 여부와 추정 확률을 확인합니다.
- 모델의 실제 테스트 지표, 기간과 혼동행렬을 확인합니다.

분석 필터를 바꾸어도 모델이 자동 재학습되지는 않습니다. 식품만으로 모델을 만들려면 데이터 범위부터 다시 정하고, 이후 시점의 평가 자료도 새로 분리해야 합니다.

## 결과를 읽을 때

이번 기본 경로에서는 Logistic Regression(C=2)이 선택됐습니다. 보정된 최종 테스트 정확도는 약 76.51%, Macro F1은 약 0.7649, serious precision 약 0.7218, recall 약 0.7991입니다. 새 조건에서 실제 실행한 값이며 원본 87.36%와 직접 비교하는 수치가 아닙니다.

최종 테스트 기간은 2024-11-26~2025-10-31, 4,853건입니다. 이 점수로 새로운 모델 설정을 고르지 마세요. 테스트 결과를 확인한 뒤 같은 자료에 맞춰 개선하면 독립적인 평가라는 의미가 줄어듭니다.

## 블로그 연결

- 데이터 점검: CSV 로딩에서 제외된 행과 수동 수정 이력을 숨기지 않고 기록하기.
- 머신러닝 원리 수정: 데이터를 먼저 나누고, 전처리를 각 학습 fold 안에서 학습하기.
- 평가: 같은 조건에서 후보를 비교하고, 확률 보정 자료와 최종 테스트를 따로 보관하기.
- 앱 연결: 수동 점수 계산 대신 저장한 파이프라인을 호출하고, 필요한 입력을 모두 받기.

노트북·주석·앱은 영어입니다. 이 환경에서는 Jupyter 커널 통신이 막혀 모든 코드 셀을 IPython 내부에서 순차 실행해 확인했습니다. 앱 필터와 실제 예측은 AppTest로 검증했으며 브라우저 화면 검토나 외부 배포를 수행한 것은 아닙니다.
